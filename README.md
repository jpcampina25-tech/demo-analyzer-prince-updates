# Demo Analyzer Prince — Atualizações

Este repositório público é usado exclusivamente para distribuir versões instaláveis e metadados de atualização do **Demo Analyzer Prince** para Windows.

- As versões publicadas aparecem em [Releases](https://github.com/jpcampina25-tech/demo-analyzer-prince-updates/releases).
- O aplicativo consulta os metadados de atualização publicados aqui.
- O código-fonte e o desenvolvimento permanecem no repositório privado [demo-analyzer-prince](https://github.com/jpcampina25-tech/demo-analyzer-prince).
- Não envie demos pessoais, arquivos de configuração ou credenciais para este repositório.

Os instaladores e arquivos `latest.yml` são publicados pelo pipeline de release do projeto.
